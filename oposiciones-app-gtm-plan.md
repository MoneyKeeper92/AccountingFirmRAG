# Oposiciones Practice App — Go-to-Market Plan

## Target Market: Small Academies Without Tech

### Why Small Academies?

| Segment | Tech Situation | Opportunity |
|---------|---------------|-------------|
| **Davante/KKR (MasterD, Medac)** | Building internally, PE money | They'll build or buy — not your customer |
| **Adams** | Has resources, may build own | Slow decision-making, possible partner |
| **Small academies (TARGET)** | PDFs, WhatsApp, paper tests | **Desperate for affordable tech** |

### Profile of Ideal Customer

- 1-10 employees (often just preparadores + admin)
- Serves ONE oposición or region
- Uses PDFs for temarios, paper/Google Forms for tests
- 50-200 active students
- No branded app or digital test platform
- Active on Instagram/social media for marketing

## Qualifying Questions (Before Outreach)

Before contacting, check:

1. **Do they have an app?** 
   - Search App Store/Play Store for their name
   - Check their website for "app" or "plataforma"

2. **What tech do they mention?**
   - "Campus virtual" = likely using generic LMS
   - "Material en PDF" = no tech, good target
   - "Plataforma propia" = already built something

3. **How big are they?**
   - Check Google reviews count
   - Check Instagram followers
   - Ideal: 50-500 students

4. **Are they active?**
   - Recent social media posts?
   - Website updated?
   - Answering Google reviews?

```
[Nombre]
```

```
"Hola, buenas. Estoy desarrollando una app de test para opositores

"Perfecto. ¿Cuál es la mejor forma de contactaros? ¿WhatsApp, email?"
```

## Beta Program Structure

### What You Offer (Free for 1 Month)

- Access to app for all their students
- Past exam questions pre-loaded (3-5 years)
- Basic progress tracking
- WhatsApp support for setup

### What You Ask in Return

- Honest feedback after 1 month
- Permission to contact students for feedback (optional)
- Testimonial if they like it (after trial)

### Follow-Up Meeting Agenda (After 1 Month)

1. "¿Qué tal la experiencia general?"
2. "¿Cuántos alumnos la han usado?"
3. "¿Qué funcionalidades echáis en falta?"
4. "¿Os gustaría añadir vuestros propios tests?"
5. "Si seguís usándola, el precio sería [X]€/mes. ¿Os encaja?"

## MVP Feature Checklist

### Must Have (Launch)

- [ ] Mobile-first test simulator
- [ ] Past exam bank (1 oposición, 3-5 years)
- [ ] User accounts (email/password)
- [ ] Basic progress tracking (tests completed, score)
- [ ] Timer for simulating real exam conditions
- [ ] Review wrong answers after test

### Nice to Have (Post-Launch)

- [ ] Analytics dashboard for academies
- [ ] Custom test upload for academies
- [ ] Spaced repetition for missed questions
- [ ] Leaderboards/gamification
- [ ] Multiple oposición tracks
- [ ] Stripe payment integration
