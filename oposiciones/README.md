# Tesón: oposiciones study platform (launch plan)

> **Tesón** · *Oposiciones, pregunta a pregunta* · `tesonopos.es`

This is the working plan for a new, separately branded Spanish business: a free (for 6 months)
test-and-analytics web app for opositores. It starts with **Auxiliar Administrativo del Estado**
and expands along the shared legal core, applying the question-bank, analytics and automation
approach proven on a CPA exam-prep platform.

This folder lives in this repository only temporarily. After account setup it moves to the new
Tesón GitHub organisation, so nothing stays linked to other businesses.
