# Tesón: oposiciones study platform (launch plan)

> **Tesón** · *Oposiciones, pregunta a pregunta* · `tesonopos.es`

This is the working plan for a new, separately branded Spanish business: a test-and-analytics
web app for opositores. It starts with **Auxiliar Administrativo del Estado** and expands along
the shared legal core.

> **Current release: private beta.** The deployable product is the 82-question,
> Constitución-only app in [`mvp/`](mvp/). It has no registration, keeps progress in the
> browser and sends pseudonymous usage analytics only after consent. The larger product,
> content and acquisition plans in documents 01–12 are the post-validation roadmap, not
> descriptions of what the private beta already contains. The executable beta runbook is
> [13_MVP_LAUNCH_TODAY.md](13_MVP_LAUNCH_TODAY.md).

This folder lives in this repository only temporarily. After account setup it moves to the new
Tesón GitHub organisation, so nothing stays linked to other businesses.

**Start here → [01_MASTER_PLAN.md](01_MASTER_PLAN.md)**. Then answer
[10_OPEN_QUESTIONS.md](10_OPEN_QUESTIONS.md) and run the Chrome session with
[03_ACCOUNTS_RUNBOOK.md](03_ACCOUNTS_RUNBOOK.md).
